# Placeholder Image Note

For the placeholder image, you have two options:

## Option 1: Download a free placeholder image
Visit: https://dummyimage.com/500x500/cccccc/666666.png&text=Product
Save it as `placeholder.jpg` in the `assets/images/` folder

## Option 2: Use any image
Place any square image (recommended 500x500px) named `placeholder.jpg` in the `assets/images/` folder

The app will use this image when a product doesn't have a photo selected.
