# Flutter Ateliers Project

This repository contains 5 Flutter workshops (ateliers) for learning Flutter development.

## Project Structure

Each atelier is in its own branch:

- **atelier1**: Basic Flutter app - Product management with list display, add, select, and delete features
- **atelier2**: Product management with ImagePicker and local list storage
- **atelier3**: Local database implementation with Drift
- **atelier4**: Firebase integration (Authentication, Firestore, Storage) or Supabase Storage
- **main**: Complete application with admin and user roles

## Branches

### Atelier 1 (Branch: atelier1)
Basic product management application with:
- Product list display
- Add products
- Select products (single/multiple)
- Delete single product
- Delete selected products

### Atelier 2 (Branch: atelier2)
Product management with image support:
- ImagePicker integration
- Product data stored in lists
- Image handling

### Atelier 3 (Branch: atelier3)
Local database implementation:
- Drift database integration
- Persistent data storage
- CRUD operations

### Atelier 4 (Branch: atelier4)
Cloud integration:
- Firebase Authentication
- Firebase Firestore
- Firebase Storage or Supabase Storage
- User management

### Atelier 5 (Branch: main)
Complete application with role-based features:

**Admin Features:**
- Add products
- Display products
- Delete products

**User Features:**
- Display products
- Add products to favorites
- View user profile

## Getting Started

```bash
# Clone the repository
git clone <repository-url>

# Switch to a specific atelier branch
git checkout atelier1

# Install dependencies
cd produitsapp
flutter pub get

# Run the app
flutter run
```
